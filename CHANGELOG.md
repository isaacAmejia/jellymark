# Changelog

## JellyMark v3.2.1 — 2026-09-30

First public JellyMark release, part of the larger JellyPi project.

- Standalone Watchlist based on and adapted from KefinTweaks Watchlist by ranaldsgift, with MIT attribution and license notices included.
- Bookmark controls, movie/show filters, and theme-aware styling.
- Series Progress, season-based Watch History, and viewing statistics.
- Import/export and playlist tools.
- Optional two-way Watchlist sync between paired users on two Jellyfin servers.
- Simple installation instructions, direct downloads, and SHA-256 checksums.

Includes Watchlist UI 3.2.1 and JellyMark Sync 3.0.1. Existing Watchlists, browser settings, and navigation hooks are preserved. This release does not add playback-state sync or TV remote controls.
